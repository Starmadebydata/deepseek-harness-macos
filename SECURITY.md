# Security Policy

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository. Include reproduction steps, affected versions, and the expected impact. Do not include live API keys, session data, or unrelated personal files.

This wrapper does not manage model credentials directly. Provider credentials remain under DeepSeek Harness control. Security issues in DeepSeek Harness itself should be reported to the upstream project.
